# 22 篇论文的独立案例设计

> 历史实现记录：用户已指出这些规则场景仍不足以表达论文的核心现象。当前开发方向以 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) 为准；下文“已写入”不代表新方案已实现或已被用户验收。

2026-09-29。以下场景已写入前端源码，尚未编译或浏览器验收。ResNet 与 Transformer 延续上一轮独立课程；本文件记录其余 22 篇。

## 设计原则

每篇先决定“读者正在操作什么”和“哪个变化能帮助理解本文”，再选择文字、图、3D 或数字。共用来源查看、代码展开与原文表格；不共用固定六步教学或双张量主实验。

可视案例只能支持与其计算范围一致的结论。原文成绩保留在独立证据区。小型算子区作为补充，不假装是主场景的同一次运行。

| 论文 | 讲解路线与读者操作 | 应该看到的变化 | 回到原文要检查什么 |
|---|---|---|---|
| AlphaGo | 棋盘标注候选 → 先猜选择 → 一次次模拟 → 调整价值/rollout 混合 | 根节点 N/Q/U 与选择改变；最高先验未必访问最多 | 策略、价值、搜索组合的证据；棋盘只是候选坐标，非围棋引擎 |
| AlphaZero | 回放一盘合法棋 → 暂停局面 → 看搜索目标 → 终局回填 | 同盘样本的 z 随行动者视角正负交替，π 不是胜者标签 | 自我对弈学习闭环、跨棋种实验；本页对局与访问记录为手工教学数据 |
| GPT-1 | 预训练托盘 → 带标签任务 → 任务输入组织 → 参数更新范围 | 各位置词表预测变成任务输出，主干也继续更新 | 无预训练对照、辅助 LM 目标的消融 |
| BERT | 选词 → MASK/随机词/保留原词 → 读左右信息 → 监督原目标 | 替换方式不改变原始监督目标，attention mask 与 MLM 输入替换不同 | 双向、NSP 等消融以及同时变化的因素 |
| GPT-2 | 同文章追加不同后缀 → 定位待续写区 | 变的是上下文，未换头也未更新权重 | TL;DR 与无提示的摘要成绩；不填入假模型摘要 |
| GPT-3 | 重命名情感标签 → 增减示例 → 交换映射 → 读者作答 | 标签约定随上下文改变，零示例不足以确定名称映射 | 真正 zero/one/few-shot 成绩与模型规模条件；规则脚本不证明模型能力 |
| Scaling Laws | 普通坐标看曲线 → 双对数 → 调指数 → 添加瓶颈 | 纯幂函数成直线，额外常数使曲线弯折 | 原文受控训练数据、拟合范围及不同资源条件；页面点不是经验观测 |
| ViT | 点一个像素 → 切 patch → 找其行列 → 展平 → 四维投影 | 该 patch 初始嵌入变化；更小 patch 增加 N 与 N² 关系数 | 预训练数据规模对成绩的影响 |
| DDPM | 猫形图/本地照片 → 时间轴加噪 → 注入 ε 估计误差 → 区分训练/生成 | 相同误差在不同 t 的重建影响与 MSE | 参数化和目标权重消融，FID/似然取舍；不把已知噪声重建当成生成 |
| CLIP | 图标/文字卡配对 → 交换卡 → 看双向损失 → 切换类别文字模式 | 训练错配与类别重排有不同含义，温度改变概率尖锐度 | 描述生成、词袋、对比目标的选择，以及零样本迁移 |
| InstructGPT | 读人工示范 → 排两条回答 → 检查奖励排序损失 → 改策略偏移与 KL | 改偏好不自动改奖励；改 KL 系数不自动执行 PPO | 独立人类偏好评测与模型奖励的区别 |
| CoT | 购物事实 → 一步步公开算式 → 注入乘法错误 → 定位首错 | 后续步骤可能沿用错误数而局部运算仍正确 | 模型规模、提示与计算器对照；算术脚本不是模型推理记录 |
| Chinchilla | 固定预算 → 移动 N → 看 D 被压缩 → 找约束曲线低点 | 参数量增大与数据不足之间的权衡 | 多种实验估计和真正训练结果；网页最优值仅来自给定 toy 函数 |
| LLaMA | 原表模型/任务取舍 → 拆 RoPE 双指针 → 改相对位置/共同平移 | 相对位置改点积，共同平移不改同频率一对分量的点积 | 数据、训练长度、架构组合；不把总体成绩归给 RoPE |
| GPT-4 报告 | 选择声明 → 区分披露/未知/越界 → 查看原页 | 纠正从输入输出反推精确架构、从单项推全能的错误 | 基准条件、公开信息与未公开范围；无需虚构 3D 网络 |
| LLaVA | 选视觉块 → 3→4 维投影 → 接入指令序列 → 切训练阶段 | 序列增长而隐藏维一致，冻结范围按阶段变化 | 指令数据与消融；手工视觉向量无实际图像问答能力 |
| SAM | 点人物衣服 → 比较候选 → 加负点或框 → 观察歧义消失/提示冲突 | 衣服与整个人可同含正点；负点筛掉不想要的粒度 | 提示任务、图像编码复用、三阶段数据引擎与跨数据集评测 |
| ReAct | 查虚构展品 → 工具失败/无关结果 → 重试/改查询 → 两跳证据回答 | 只有成功返回才能更新已知事实，答案必须有完整证据链 | 推理与行动组合、任务间效果差异；读者执行而非假模型轨迹 |
| Toolformer | 候选调用 → 固定返回 → 三种上下文评分 → 按收益过滤 | 工具存在不等于有用；空返回基线隔离调用文本作用 | 训练后 enabled/disabled 消融与基模型对照 |
| Mixtral | 选 token → 改特征 → 看 Top-2 路径 → 手算一个输出维 → 查负载 | 不同 token 可选不同专家，输出加权和不拼接维度 | 活跃参数、总参数和真实延迟的区别 |
| DeepSeek-R1 | 四份算术答案 → 校验奖励 → 算组内优势/裁剪 → 对照两条训练路线 | 全部同奖时无相对信号；R1 与 R1-Zero 阶段不同 | 训练过程及评测预算，不能只归因某个目标公式 |
| MMaDA | 条件区固定 → 点击响应 mask → 查看选位 NLL → 对照 AR 顺序 | 可见上下文在两侧，只有被遮位置计重建损失 | 预训练、混合长 CoT、UniGRPO 阶段消融与采样区别 |

## 代码组织与边界

- `frontend/src/papers/casePlans.ts`：22 篇各自的教学问题、操作起点、证据衔接和边界。
- `frontend/src/components/PaperCaseLesson.vue`：课程分发、原文论证与代码来源，不再决定统一六步阅读流程。
- `components/cases/`：按相邻计算工具组织七个源文件，每个论文分支有自己的交互与布局。Search / Language / Vision / Multimodal / Training / Reasoning / Evidence 共覆盖 22 个 ID。共享像素绘制器 `PixelPlane.vue` 与界面样式。
- `PaperLesson.vue`：01 → ResNetPaper；04 → TransformerPaper；其余 → PaperCaseLesson。旧 PaperResearch/PaperComparison 保留在磁盘，但不在当前课程入口执行。
- 新场景的临时操作状态在离开课程后重置；“已学完”标记仍沿用旧存储。没有声称旧六步章节位置控制新场景。

## 数据来源层级

1. 01 照片响应使用既有本地模型 API；本轮没有运行它。
2. 新场景中的小型向量、损失、路由、像素和查询环境由浏览器确定性计算或明确的教学记录提供。
3. 28 组原文结果仍来自前轮核对的研究数据模块。本轮没有添加新的性能成绩、训练轨迹或声称通读全部论文；补看了 CLIP、SAM、Toolformer 的相关提取段落。

本轮不下载模型、不训练、不接入外部推理服务。DDPM 的图片读取只用于浏览器内灰度与噪声运算，不上传到 API。
