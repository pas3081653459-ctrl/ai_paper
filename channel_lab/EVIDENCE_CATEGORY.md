## 数据来源及边界

### 09：近似读图，不是原始测量

`frontend/src/papers/scalingFixture.ts`：Kaplan et al. Figure 6 右图，6 层橙色曲线。已查看公开原文渲染图，手工读取六个近似坐标：

| 非 embedding 参数 N | 测试损失（nats，近似） | 本课用途 |
|---:|---:|---|
| 1.6e6 | 3.80 | 拟合候选 |
| 6.5e6 | 3.40 | 拟合候选 |
| 2.7e7 | 3.10 | 拟合候选 |
| 1.4e8 | 2.75 | 拟合候选 |
| 2.8e8 | 2.62 | 留出 |
| 1.4e9 | 2.41 | 留出 |

原始图有对数坐标、重叠曲线和有限渲染分辨率；这些坐标被舍入，**没有经校准的读图误差界**。不能用它们复现或重新估计论文的精确指数。留出划分由本课人为选择，原论文没有使用此划分。没有用原文幂律公式反算散点。

回归是 `ln L = a + b ln N` 的 OLS，α = −b；仅使用被选中的非留出点，不加入不可约损失项。隐藏的 loss 不参与拟合及纵轴范围计算；重复查看留出结果后调范围不再属于严格盲测。公开数据面板和导出的记录允许核查全部数字，并不保密留出数据。

原文：[Figure 6 / PDF p8](https://arxiv.org/pdf/2001.08361#page=8)。可选导入沿用 TRACE_FORMATS 的09契约，要求至少两个不同 x 的非留出点、一个留出点。拒绝超出本图数值范围的坐标；导入失败保留当前案例。恢复按钮返回内置案例并清除上传来源显示。

### 15：约束算术、拟合指数、真实成绩分开

教学预算固定为 `4.2e23 FLOPs`，`C≈6ND`；70B 对应 1T tokens，280B 对应 0.25T。**这不是论文 Gopher/Chinchilla 的实际预算配方。** 原文 Table 1 配置另列：280B/300B tokens 与70B/1.4T tokens。

Table 2 的旧估计及三路线指数用于相对扩展倍数，界面照录 bootstrap 第10–90百分位。原表参数化路线的 a 点估计与区间不一致，明确保留并说明，不擅自修正，不伪造损失曲线或置信带。Table 6 使用 MMLU 5-shot 的60.0与67.6；摘要67.5的差异保留说明。

原文：[Chinchilla](https://arxiv.org/pdf/2203.15556)，§3 / Table 1、2（p8）、6。既有 `researchMethods.ts` 提供指数和成绩，组件补充实验任务。

### 17：原文五系统成绩，存储只是估算

[LLaMA Table 3 / PDF p4](https://arxiv.org/pdf/2302.13971#page=4)，zero-shot：

| 模型 | HellaSwag | PIQA | ARC-challenge |
|---|---:|---:|---:|
| GPT-3 175B | 78.9 | 81.0 | 51.4 |
| LLaMA 7B | 76.1 | 79.8 | 47.6 |
| LLaMA 13B | 79.2 | 80.1 | 52.7 |
| LLaMA 33B | 82.8 | 82.3 | 57.8 |
| LLaMA 65B | 84.2 | 82.8 | 56.0 |

固定任务最小候选依次为13B、33B、33B。选择4/8bit后只估算纯权重，不依据未量化成绩判定质量达标；16/32bit同样只是以原文分数做候选筛选，没有重新测量对应精度质量。GB采用十进制；未包含KV cache、激活、元数据、运行时，不预测时延。跨系统成绩不能隔离单个算子的作用。

### 18：结论有不同类型

[GPT-4 Technical Report](https://arxiv.org/pdf/2303.08774)，p2披露边界、p7 Table 2。MMLU 5-shot、HumanEval 0-shot；DROP为F1，GPT-4 3-shot与专用QDGAT设置不同。

五条参考判定：两项成绩提升→支持；特定路由贡献→不足；DROP超过专用系统→反驳；已公开层数/完整配方→反驳；报告证明当前同名产品成绩→不足。特别区分“是否披露”的可核查事实与“未知架构是什么”的信息缺失。

## 依赖与部署

- **新增 npm / Python 包：无。新增模型权重、训练数据、模型服务：无。** 使用现有Vue、TypeScript、SVG及浏览器API。
- 固定数据随前端源码打包，计算在浏览器完成。`localStorage` 保存作答和最多4000字笔记；键为 `channel-lab:evidence:v1:<paperId>`。禁用或损坏时仍能使用页面并导出记录，提示保存失败。探索滑块刷新后回到固定条件，原课程“已学完”标记独立保存。
- “导出学习记录”生成本地JSON，包含作答、当前条件和来源说明；这是学习记录，不是模型轨迹，不能用TraceLoader当作实验输入。上传的实验点不会自动保存到localStorage，也不上传服务器。
- 本地PDF按钮沿用FastAPI `/api/papers/{id}`。默认 `CHANNEL_LAB_PAPER_ROOT=/Users/Zhuanz/论文`，从既有 `paper_sources.json` 白名单读取：

```text
<CHANNEL_LAB_PAPER_ROOT>/
  ai-papers-01/09_scaling-laws-kaplan.pdf
  ai-papers-02/15_chinchilla.pdf
  ai-papers-02/17_llama.pdf
  ai-papers-03/18_gpt-4-technical-report.pdf
```

没有本地PDF或后端时，固定实验仍不依赖该接口；可使用每课的公开原文链接（需要网络）。部署到服务器时应显式配置该目录；保留 `/api` 反向代理，否则仅本地原文按钮不能读取。

以下仅供用户之后手动执行，本轮没有执行。已有前端依赖时，在 `channel_lab/frontend`：

```bash
npm run dev
# 或需要生产部署时：
npm run build
```

新环境按 README 安装已有基础依赖即可，不需要为这四课安装 Transformers 或可选模型包。生产站点必须更新新构建的dist；仅重启旧dist不会出现新分类。Vite开发服务的 `/api` 已代理到 `127.0.0.1:8000`；若后端端口改变，按现有配置修改代理。
