## 阅读规则

术语提供中文、英文、直白释义、课内语境、可观察例子、关联论文标题/章节/PDF页。中文标题为阅读译名，不冒充官方译名。本站教学词（Other、首错、证据链等）单独注明，不当作论文命名。

“在哪篇论文使用”与“最早是谁提出”分开。当前没有完成所有词条的历史溯源；一般数学基础不会因为链接某论文而归属于该论文。GRPO也明确标为R1所采用的算法，而非声称由R1首次提出。部分术语链接使用既有课程的相关章节范围，不声称已逐词核对出现页。

数学页包含先修基础、符号表、分步公式/解释、参数滑块、逐项代入、复位、教学边界、原文与实验回链。公式为可选择文本，用Unicode数学字符和数学字体呈现；没有新增KaTeX/MathJax或PDF渲染包。

## 数学主题

| ID | 主题 | 数值练习边界 |
|---|---|---|
| residual | 残差映射、投影、局部雅可比 | 单标量主分支+捷径+ReLU |
| attention | 缩放点积、mask、softmax、Value汇总 | 两分数/一个Query的标量Value例子 |
| likelihood | 自回归似然、one-hot交叉熵、NLL、工具筛选思路 | 单个目标概率的NLL |
| diffusion | 一步加噪、两步方差合并、闭式前向 | 单像素固定ε，不是完整轨迹 |
| contrast | 单位向量、图文分数、对称交叉熵 | 两候选softmax，不运行CLIP |
| moe | Top-k、选中概率归一化、加权合并 | 3选2，手动固定专家输出 |
| advantage | 均值、总体标准差、相对优势 | 四奖励；零方差置零为教学约定 |
| budget | C≈6ND、参数化损失、驻点与幂指数 | 只计算预算，不预测质量 |
| selfplay | 访问分布、联合策略/价值损失、胜负视角 | 只计算价值项，不训练 |

首次直接进入某主题会初始化该主题的数值；路由变化重建页面，避免不同主题共用旧滑块值。概率滑块避免0，温度为正，softmax减最大值，MoE平分按编号选择，组内零方差显式处理。恢复初值不会影响原实验标签页。
