## InstructGPT：盲评与偏好分歧（13）

默认是**本站手写**的图书馆概括题及三个回答，用来辨别遵循指令、事实依据和简洁程度；不是base/SFT/RLHF生成，奖励全部null。用户可导入真实不同阶段的回答。

- 浏览器洗牌、匿名A/B/C标签；确认排序后才揭示阶段和记录奖励。来源面板在揭示前也隐藏。
- 三种评价准则分别保留；已知来源后再评标记为复评，不能算独立盲评。界面隐藏不是安全隔离，读过原JSON或回答自报模型名称都可能破盲。
- 当前页面记录多轮；显示同题同准则最近两轮的回答对顺序变化，以及读者排序和记录奖励的配对一致数量。奖励相同或缺失的对不计入分母。
- 轮次数不是人数；没有伪造评审者、奖励模型或人类偏好数据。导出 `kind=learner-preference-review` 包含评价准则、排序、是否已知来源、原始条目和来源声明。
- SFT / 奖励模型 / 策略优化三个解释卡说明当前评价位于哪里；没有奖励训练或PPO。

没有真实记录时只能做手写练习，不能声称观察到“奖励模型高分但事实错误”的真实模型案例。奖励值也只能视为提供者声明，需核查其奖励模型版本和量纲。

## CoT：最终结果与过程分开核验（14）

入口手写反例：3×4被写成7、7−2被写成10，最终数字碰巧正确。明确不是模型输出，先用来理解“最终正确不能保证过程正确”。

真实实验复用本地GPT-2原始架构权重，本站固定英语整数题来自 `backend/reasoning_cases.json`：乘后减、减后乘、加后除。用户选择1–3题、每条件32/64/128新token。两条件均同模型、贪心、同长度上限：直接回答 vs 简短、可检查的公开解答。不是论文few-shot示例设计复现，也不索取模型私有思维。

- 实际输出按换行逐步揭示；换行不等于逻辑步骤。读者标记首个可核查错误、未发现错误或无法判断。
- 独立读取输出最后一行 `FINAL: 整数`；要求全文恰好一条有效FINAL整行，最后非空行必须是它。支持符号和最多12位ASCII数字，规范化整数；不支持小数、单位、分数或一般数学等价表达。
- 缺标记、多标记、空输出、额外解释尾行计格式失败；目标匹配与读者首错判断分开，格式失败不等于已经证明不会计算。
- 按题型列正确数/总数，保留实际提示、token、停止原因和失败输出；不拿三道本站题当原文成绩。
- 可导出模型轨迹和读者标注；编辑输入清除旧结果与标注。旧版单题记录在独立折叠区查看。

## Toolformer：实际工具返回与对齐损失（22）

默认两个候选共用“7盒、每盒8个苹果”的上下文与目标后缀：相关调用7×8、无关调用2+2。这些是**读者提出的候选**，没有伪装成模型采样调用位置。

- 可改上下文、目标后缀、操作数、操作符；仅整数范围[-10000,10000]的+/-/*，无eval、终端、网络工具或任意代码。
- 浏览器先算预览；点击评分时后端独立执行工具，保留实际返回。三个上下文为无调用、带调用但无返回、带调用与返回。
- **目标后缀只分词一次**，同一组target_ids追加到三个分别编码的prefix_ids之后。避免跨条件BPE边界改变目标；这不等于对三份完整拼接字符串各自自然分词。页面同时显示目标起点、实际前缀ID与目标ID。
- 每个条件对同一目标做teacher-forced前向：用前一个位置的logits预测当前目标ID，`NLL=-log_softmax(logits)[target_id]`。一次评分的目标长度1–64，最长上下文由模型决定，不静默截断。
- 默认权重1/T，显示平均NLL，单位nats/token；导入数据权重原样使用，不偷偷归一化。
- `Δ=min(L_without,L_empty)-L_with`；先在**整段总损失**中选基线，瀑布图再累加同一基线各token贡献。不能先逐token取min再当作同一个公式。
- 阈值滑块只改变保留/丢弃，负收益如实展示；导出的是带阈值和来源的筛选记录，不是训练后的模型。未执行原文候选采样或微调。

## DeepSeek-R1：候选奖励与组内比较（24）

奖励开关是纯数学算例：手动切0/1，包括全部0、全部1，观察总体标准差和优势；不配上虚构回答冒充模型实验。

真实候选仍用明确标注的GPT-2替代模型，同一个简短公开解答提示，多项式随机采样：每题2/4/8条、温度0.1–2、seed0–10^6、每条最多64新token。每题第i条使用seed+i，各题重新用同一组seed；这不保证不同题随机变量独立。CPU generator对完整温度softmax采样，无top-k/top-p。记录p为温度调整后的采样分布，跨设备/版本不保证逐字复现。

- 与14共用独立FINAL整数检查，每条奖励0/1；空/格式失败计0但展示原因。
- `mean=Σr/G`、总体 `std=sqrt(Σ(r−mean)^2/G)`、`A=(r−mean)/std`；std=0按本课约定全部置0，不加隐形epsilon。
- 重复输出保留，不为了凑多样性改写候选；每条展示实际token数，长回答不自动加分。
- 跨题列成功候选数/采样数与平均输出token，不命名为论文pass@1或self-consistency，也不计算虚构训练提升。
- R1/R1-Zero外部记录可分别导入；本地生成固定route=substitute。没有GRPO的策略比率、裁剪、KL或任何训练更新。

## 依赖、本地文件与部署

不增加npm包、数据库或外部模型服务。13无需权重。14/22/24复用上一类的原始GPT-2配置和Python依赖，不要求下载GPT-3、Toolformer、R1或奖励模型。

现有 `requirements-language.txt` 复用候选约束：transformers==4.55.4、huggingface-hub>=0.34,<1.0、safetensors>=0.4.3,<0.7，另需项目基础PyTorch/FastAPI等。它不是已运行验证的锁文件。本轮没有安装。以后用户若需要配置，从仓库根目录手动执行：

```bash
source .venv/bin/activate
pip install -r channel_lab/requirements.txt -r channel_lab/requirements-language.txt
export CHANNEL_LAB_GPT2_MODEL="$PWD/channel_lab/models/gpt2"
export CHANNEL_LAB_LANGUAGE_DEVICE=cpu
```

目录必须是同revision的GPT2LMHeadModel兼容文件：

```text
models/gpt2/
  config.json            # model_type=gpt2
  model.safetensors
  tokenizer_config.json
  vocab.json
  merges.txt
```

如果来源有special_tokens_map.json、added_tokens.json、tokenizer.json，同步保留并记录指纹。完整基础说明见 [LANGUAGE_CATEGORY.md](LANGUAGE_CATEGORY.md)。只支持单文件本地safetensors、float32和cpu/mps/cuda；缺参数/输出头时拒绝随机补全结果。文件与版本检查不等于加载和推理通过。全部local_files_only及offline worker，不自动下载，不加载远程代码。

### API

- `GET /api/experiments/training/config/14|22|24`：复用GPT2配置检查。
- `POST /api/experiments/training/run`：paper_id=14/22/24。
- 14/24：task_ids为boxes/tickets/books的1–3个不重复ID；max_new_tokens=8–128（页面分别32/64/128或固定64）；24另有samples=2–8、seed、temperature。
- 22：candidates=1–3条，每条prefix≤800字符、target≤200字符、a/b严格整数、op为+/-/*；空白上下文/目标拒绝。页面默认两条，可独立编辑。
- 请求体≤16KiB；180秒是**整个请求**的加载和所有生成/评分总期限，超时不返回半批“完整结果”。CPU多题、多候选可能超时，应减少题目/候选/长度。共用现有本地模型进程锁、断连/取消/超时清理。
- 输出采用v1外层并加课程v2 data；记录文件/权重/代码/题集/请求指纹、设备、包版本与真实解码设置。没有新的磁盘模型缓存或训练服务。

前端编辑实验参数会取消在途请求并清除旧输出，迟到响应不能覆盖新输入。13评价轮次、14首错标注是当前页面内存；课末学习笔记用localStorage保存，模型轨迹不自动持久化。导入JSON≤20MiB，结构和数值校验不证明来源真实。
